# DashTrack advertising ownership verification

This public repository serves the root of https://relentless860.github.io/.
It contains only the developer landing page and public app-ads.txt seller record.
No app source, signing keys, credentials, user records or private media belong here.

Google's crawler uses the hostname of the existing developer website, not its
project subdirectory. Publishing a file only under /dashtrack-pro-policy/
would not satisfy the required /app-ads.txt root URL.

The exact seller record was copied from the owner's authenticated AdMob
"Set up app-ads.txt" instructions on October 25, 2026. It authorizes the
existing Google publisher account only; it does not enable ads or prove app
verification/approval. The app-specific policy remains in its existing repo.

GitHub Pages: main branch, root. Existing project-site URLs are unchanged.
